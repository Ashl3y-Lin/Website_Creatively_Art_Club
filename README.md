# Creatively Art Club website

Bilingual (English / Español) website for Creatively Art Club at the American Nicaraguan School.

## Folder structure
```
index.html          main page
ceremony.html       4th Creative Challenge award ceremony page
css/style.css       styles for the main page
css/ceremony.css    styles for the ceremony page
js/i18n.js          English ⇄ Spanish translations and language switch
js/main.js          interactions: bulb mascot, team photo, sliders, viewers, pop-ups
js/ceremony.js      photo viewer for the ceremony page
assets/img/         all photos, logos and animations (full quality)
assets/video/       short videos used in the event galleries
```

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `creatively-club`).
2. Click **Add file → Upload files** and drag in **everything inside this folder** (index.html, ceremony.html, README.md and the css, js and assets folders). Keep the folder names exactly as they are.
3. Click **Commit changes**.
4. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
5. After a minute, the site is live at `https://YOUR-USERNAME.github.io/creatively-club/`.

## Editing
- Text in English lives in `index.html`; its Spanish version is in `js/i18n.js` (search for the English sentence to find its translation).
- To replace a photo, upload a new file to `assets/img/` with the **same file name**.
